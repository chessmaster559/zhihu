## 当前能力

- 128×128 看山桌宠，启动打招呼、待机、晃悠、玩耍、电脑和瞌睡动作。
- 16 kHz ADC DMA 采音、24 kHz 差分 PDM 播放，设备端语音和网络协议沿用 XiaoZhi。
- 底部识别字幕、漫画播报气泡、摸头爱心、睡眠 Zzz、昼夜冰屋背景。
- 原配 BME690 子板的自检与温湿压/原始气体电阻采集，以及鼻子 MCP 查询。
- 换装 BMI270/BMM350 子板并关闭鼻子配置后，可恢复 BMI270 动作感知。

当前主配置为鼻子模式。两类原配子板占用同一个 Shuttle 插座；固件不会在鼻子
模式下启动 BMI270 任务。桌宠动画和触摸反馈不依赖 IMU。

## 能力与验证边界

“闻到变化”来自气体传感器响应；本仓库尚无 BSEC IAQ 配置及训练过的气味分类
模型，不能给出咖啡/香水等气味类别、甲醛浓度或真实 CO₂ 浓度。用户反馈能闻到
但不能分辨气味，与当前实现一致。[鼻子文档](nose-and-mcp.md)说明后续训练路线。

最新源码版本已构建并写入设备；最新状态提示和查询日志尚缺复位后的完整实机
回归记录。前一版本已有 BME690 自检、连续采样、联网、动画和麦克风日志。
具体证据与版本对应关系见[验证记录](validation-and-limits.md)，不以一次编译代替整机验证。

## 阅读顺序与维护

第一次使用：硬件 → 构建烧录 → 桌宠交互 → 鼻子查询。修改代码前先看架构和
根目录 [AGENTS.md](../../AGENTS.md)。修改 SDK、分区、引脚或素材格式时同步更新文档。

本目录是当前说明；旧的 `docs/c5-*.md` 保留分阶段调试过程，涉及“未烧录”、
旧包大小或旧 UI 的句子应按其日期阅读，以此目录的验证表为当前入口。
